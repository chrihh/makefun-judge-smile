One line, at most 200 characters, about a small good thing that
happened today — written to make the judge smile. The generator
fails, a neighbour quietly answers with an extension cord over the
fence, and the cord renews more than the tea: a truce about his
mango tree.

The line the program writes:

> The generator coughed twice, gave up, and the neighbour silently ran an extension cord over the fence — my tea stayed hot, and so did our truce about his mango tree.

## Run it

```sh
python3 main.py
```

This writes the line above to `/output/entry.txt` as UTF-8, with
no trailing newline. The line is 165 characters, inside the
1–200 limit, and is a single line.
